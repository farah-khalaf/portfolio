Vulnerability Assessment & Web Security Labs

Hands-on penetration testing and vulnerability assessment work across a deliberately vulnerable web application and a set of self-built multi-OS attack labs.

OWASP Juice Shop Kali Linux Metasploitable 2 VMware

Web application testing

  • Executed simulated penetration tests against OWASP Juice Shop, a purpose-built vulnerable web application used for training.
  • Identified authentication flaws — weaknesses in how the application verifies who a user is.
  • Identified information disclosure risks — points where the application reveals more than it should to an attacker.

Lab environment

  • Architected multi-OS penetration testing labs using VMware Workstation to run isolated attacker and target machines side by side.
  • Used Kali Linux as the attacking platform and Metasploitable 2 as an intentionally vulnerable target.
  • Evaluated exploit vectors across the lab to understand how a vulnerability moves from a theoretical weakness to something actually exploitable.
