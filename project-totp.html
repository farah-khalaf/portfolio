TOTP Token Security Analyzer

A self-contained tool for exploring how Time-based One-Time Passwords actually behave — how strong the shared secret needs to be, how the 30-second validity window works, and what a naive brute-force attempt against it looks like.

HTML / CSS / JavaScript Client-side, no backend

Try it

This is the actual project running — not a screenshot. Enter a secret key and a 6-digit token, or just watch the generated TOTP roll over every 30 seconds.

demos/totp/index.htmllive

What it checks

  • Validates that the entered secret key is long enough to resist brute-forcing, and flags weak, short secrets.
  • Confirms the submitted token matches the expected 6-digit numeric format before treating it as valid.
  • Generates a fresh 6-digit TOTP every 30 seconds with a visible countdown, mirroring how real TOTP validity windows work.
  • Verifies a submitted token against the currently active one, and rejects it once the window has expired.
  • Runs a simulated attack that models rate-limiting: past a handful of attempts, further guesses are blocked.

Why it matters: most TOTP implementations are only as strong as their weakest supporting rule — a short secret, a missing expiry check, or no rate limiting on verification attempts. This project isolates each of those checks so they're easy to reason about individually.
