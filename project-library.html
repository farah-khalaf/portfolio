University Library System

A library management system focused on relational query logic — modeling books, members, and borrowing rules as data, then reasoning over that data with Prolog and SQL.

Prolog SQL

What it covers

  • Designed relational data structures to represent the library's core entities — books, members, and loans.
  • Developed query logic in Prolog to answer rule-based questions over that data, such as availability and borrowing eligibility.
  • Implemented the equivalent relational queries in SQL, reinforcing how the same logical questions are expressed differently across a logic-programming language and a relational database.
